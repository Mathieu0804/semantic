## 🚀 INSTALLATION & DÉMARRAGE

### Installation Express (5 minutes)

```bash
# 1. Setup automatique
node setup.js

# 2. Configuration
cp .env.example .env
# Éditer .env avec vos paramètres

# 3. Base de données
createdb pme_ai_platform
psql pme_ai_platform < database/schemas/init.sql
psql pme_ai_platform < database/migrations/001_add_performance_indexes.sql

# 4. IA locale
ollama pull llama3:8b

# 5. Démarrage
docker-compose up -d
```

### Accès aux Services

- **Site Creator**: http://localhost:3000
- **Catalog Manager**: http://localhost:3001
- **Identity Manager**: http://localhost:3002
- **API Backend**: http://localhost:5000
- **MCP Server**: http://localhost:5001
