## 📖 COURS DISPONIBLES

**Fichier :** `COURS_01_LES_BASES.md`  
**Durée :** 1-2 heures  
**Niveau :** Débutant

**Ce que vous apprendrez :**
- ✅ Comment fonctionne Internet
- ✅ Qu'est-ce qu'un serveur web

- ✅ Base de données PostgreSQL
- ✅ Architecture client-serveur

**Concepts clés :**

- Bibliothèque, framework
- Port, localhost
- SQL, table, requête

## 📝 MÉTHODOLOGIE D'APPRENTISSAGE

### **1. Lire activement**
- Ne pas se contenter de lire
- Noter les concepts clés
- Faire des schémas

### **2. Pratiquer**

- Essayer sans regarder la solution
- Comparer votre solution

- Écrire vos propres notes
- Créer vos propres exemples

## 💡 ASTUCES POUR BIEN APPRENDRE

### **Ne pas avoir peur de l'erreur**
```
❌ "J'ai une erreur, je suis nul"
✅ "J'ai une erreur, je vais comprendre pourquoi"
```

### **Lire les messages d'erreur**
```
SyntaxError: Unexpected token }
              └─ Jeton inattendu
              
Cherchez une } en trop ou une { manquante
```

### **Utiliser console.log()**
```javascript
const user = req.body;
console.log('User reçu :', user);
// Affiche ce que contient user
```
